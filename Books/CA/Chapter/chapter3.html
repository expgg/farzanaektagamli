অধ্যায় ৩: সিপিইউ ডিজাইনের বেসিক

অতি সংক্ষিপ্ত প্রশ্ন

১। ALU-এর কাজ কী?

পরীক্ষায় লেখার জন্য: ALU (Arithmetic Logic Unit) এর প্রধান কাজ হলো সিপিইউর অভ্যন্তরে সকল প্রকার গাণিতিক (যেমন: যোগ, বিয়োগ, গুণ, ভাগ) এবং যৌক্তিক (যেমন: AND, OR, NOT, XOR) অপারেশন সম্পাদন করা।

সহজ ভাষায় ব্যাখ্যা: ALU হলো সিপিইউর ক্যালকুলেটর। এটা সব হিসাবনিকাশ (যোগ-বিয়োগ) আর যুক্তির কাজ (হ্যাঁ/না তুলনা) করে।

একদম সহজ ব্যাখ্যা: তোমার ব্রেইনের যে অংশটা অঙ্ক কষে বা যুক্তি দিয়ে চিন্তা করে, সেটাই ALU।

২। কন্ট্রোল ইউনিট (CU)-এর কাজ কী?

পরীক্ষায় লেখার জন্য: কন্ট্রোল ইউনিট (CU) সিপিইউ তথা পুরো কম্পিউটার সিস্টেমের কার্যক্রম পরিচালনা ও নিয়ন্ত্রণ করে। এটি মেমরি থেকে ইন্সট্রাকশন ফেচ করে, ডিকোড করে এবং এক্সিকিউট করার জন্য প্রয়োজনীয় কন্ট্রোল সিগন্যাল তৈরি করে ALU, রেজিস্টার ও অন্যান্য ইউনিটে প্রেরণ করে।

সহজ ভাষায় ব্যাখ্যা: কন্ট্রোল ইউনিট হলো সিপিইউর ম্যানেজার। সে নির্দেশ আনে, বোঝে কী করতে হবে, আর সেই অনুযায়ী மற்ற সব অংশকে দিয়ে কাজটা করিয়ে নেয়।

একদম সহজ ব্যাখ্যা: ট্র্যাফিক পুলিশ যেমন রাস্তার সব গাড়ি কন্ট্রোল করে, কন্ট্রোল ইউনিটও তেমনি কম্পিউটারের সব কাজ কন্ট্রোল করে।

৩। CPU বলতে কী বুঝ?

পরীক্ষায় লেখার জন্য: CPU এর পূর্ণরূপ হলো Central Processing Unit। এটি কম্পিউটারের প্রধান কার্যকরী অংশ বা মস্তিষ্ক, যা প্রোগ্রামের ইন্সট্রাকশনগুলো এক্সিকিউট করে এবং ডেটা প্রসেসিং এর কাজ সম্পন্ন করে। এর প্রধান অংশ হলো কন্ট্রোল ইউনিট (CU) এবং অ্যারিথমেটিক লজিক ইউনিট (ALU)।

সহজ ভাষায় ব্যাখ্যা: CPU হলো কম্পিউটারের ব্রেইন। এটাই সব হিসাবনিকাশ করে আর পুরো কম্পিউটারটাকে চালায়।

একদম সহজ ব্যাখ্যা: মানুষের শরীরের যেমন ব্রেইন, কম্পিউটারের তেমনি CPU।

৪। ফুল অ্যাডার কাকে বলে।

পরীক্ষায় লেখার জন্য: ফুল অ্যাডার (Full Adder) হলো একটি ডিজিটাল লজিক সার্কিট যা তিনটি বাইনারি বিট (দুটি ইনপুট বিট A ও B, এবং একটি পূর্ববর্তী Carry-in বিট Cin) যোগ করে দুটি আউটপুট উৎপন্ন করে: একটি Sum বিট (S) এবং একটি Carry-out বিট (Cout)।

সহজ ভাষায় ব্যাখ্যা: ফুল অ্যাডার হলো একটা ইলেকট্রনিক সার্কিট যেটা তিনটা বাইনারি সংখ্যা (০ বা ১) যোগ করতে পারে। যোগ করে সে একটা যোগফল (Sum) আর একটা হাতে থাকা সংখ্যা (Carry) বের করে দেয়।

একদম সহজ ব্যাখ্যা: তুমি যখন হাতে রেখে যোগ করো (যেমন ৮+৭=১৫, ৫ নামলো হাতে ১), ফুল অ্যাডারও তেমনি তিনটা বিট যোগ করে যোগফল আর হাতে থাকা সংখ্যাটা বের করে।

৫। Co-processor বলতে কী বুঝ?

পরীক্ষায় লেখার জন্য: কো-প্রসেসর (Co-processor) হলো একটি বিশেষায়িত প্রসেসিং ইউনিট যা মূল সিপিইউকে নির্দিষ্ট কিছু জটিল বা সময়সাপেক্ষ কাজ (যেমন: ফ্লোটিং-পয়েন্ট গাণিতিক হিসাব, গ্রাফিক্স প্রসেসিং) সম্পাদনে সহায়তা করার জন্য ডিজাইন করা হয়। এটি মূল সিপিইউর পাশাপাশি কাজ করে তার কাজের চাপ কমায় এবং সিস্টেমের পারফরম্যান্স বৃদ্ধি করে।

সহজ ভাষায় ব্যাখ্যা: কো-প্রসেসর হলো মেইন সিপিইউর একজন স্পেশালিস্ট সহকারী। কিছু বিশেষ কাজ (যেমন খুব কঠিন অঙ্ক বা গ্রাফিক্সের কাজ) যা করতে মেইন সিপিইউর অনেক সময় লাগে বা কষ্ট হয়, সেই কাজগুলো এই কো-প্রসেসর করে দেয়। যেমন গ্রাফিক্স কার্ডের GPU একটা কো-প্রসেসর।

একদম সহজ ব্যাখ্যা: মনে করো রিফাত (মেইন CPU) রান্না করছে। তার একজন সহকারী (কো-প্রসেসর) আছে যে শুধু সবজি কাটার কাজটা খুব দ্রুত করতে পারে। রিফাত তাকে সবজি কাটতে দিয়ে নিজে অন্য কাজ করে।

৬। কো-প্রসেসরের কাজ লেখ?

পরীক্ষায় লেখার জন্য: কো-প্রসেসরের প্রধান কাজ হলো মূল সিপিইউকে নির্দিষ্ট ধরনের বিশেষায়িত ও জটিল কম্পিউটেশনাল টাস্ক থেকে অব্যাহতি দেওয়া এবং সেই কাজগুলো নিজে দ্রুত ও দক্ষতার সাথে সম্পাদন করা। যেমন: ফ্লোটিং-পয়েন্ট গাণিতিক হিসাব, গ্রাফিক্স রেন্ডারিং, ডিজিটাল সিগন্যাল প্রসেসিং, ক্রিপ্টোগ্রাফি ইত্যাদি।

সহজ ভাষায় ব্যাখ্যা: কো-প্রসেসরের কাজ হলো স্পেশাল কিছু কাজ করা যা মেইন সিপিইউ ভালো পারে না বা করতে গেলে স্লো হয়ে যায়। যেমন কঠিন অংক করা বা ভিডিও গেমের গ্রাফিক্স বানানো।

একদম সহজ ব্যাখ্যা: সবজি কাটার সহকারীর কাজ হলো শুধু দ্রুত আর সুন্দর করে সবজি কেটে দেওয়া।

৭। MAR ও MBR-এর কাজ লেখ?

পরীক্ষায় লেখার জন্য:

  • MAR (Memory Address Register): এটি সেই মেমরি লোকেশনের অ্যাড্রেস ধারণ করে যেখান থেকে ডেটা পড়া বা লেখা হবে।
  • MBR (Memory Buffer Register) বা MDR (Memory Data Register):** এটি মেমরি থেকে পড়া ডেটা অথবা মেমরিতে লেখার জন্য প্রস্তুত ডেটা সাময়িকভাবে ধারণ করে।

সহজ ভাষায় ব্যাখ্যা:

  • MAR: মেমরির ঠিকানা লিখে রাখে।
  • MBR: মেমরি থেকে আনা বা মেমরিতে পাঠানো ডেটাটা ধরে রাখে।

একদম সহজ ব্যাখ্যা:

  • MAR: লাইব্রেরির বইয়ের তাক নম্বর।
  • MBR: তাক থেকে আনা বইটা বা তাকি রাখতে দেওয়া বইটা।

৮। MAR ও MBR-এর পূর্ণনাম লেখ।

পরীক্ষায় লেখার জন্য:

  • MAR: Memory Address Register
  • MBR: Memory Buffer Register (অথবা MDR: Memory Data Register)

সহজ ভাষায় ব্যাখ্যা: MAR মানে মেমরি অ্যাড্রেস রেজিস্টার, MBR মানে মেমরি বাফার রেজিস্টার।

একদম সহজ ব্যাখ্যা: এদের পুরো নাম।

সংক্ষিপ্ত প্রশ্নঃ

১। একটি আদর্শ সিপিইউ (CPU)-এর ব্লকচিত্র অঙ্কন করে কন্ট্রোল ইউনিটের কাজ দেখাও?

পরীক্ষায় লেখার জন্য:

সিপিইউ ব্লকচিত্র:


           +---------------------------+
           |     কন্ট্রোল ইউনিট (CU)    |-------------+
           +-----------+---------------+             | --> কন্ট্রোল সিগন্যাল
                       | ডিকোড (IR থেকে)           |
           +-----------V---------------+             |
           |       রেজিস্টারসমূহ        |             |
           | (PC, IR, MAR, MBR, GPRs...) |<------------+
           +-----------+---------------+             |
                       ^  | ডেটা/অ্যাড্রেস           |
                       |  V                       |
           +-----------+---------------+             |
           | অ্যারিথমেটিক লজিক ইউনিট   |<------------+
           |          (ALU)            |
           +---------------------------+
                       ^  |
                       |--+--- সিস্টেম বাস (ডেটা, অ্যাড্রেস, কন্ট্রোল)

কন্ট্রোল ইউনিটের কাজ: কন্ট্রোল ইউনিট (CU) ইন্সট্রাকশন রেজিস্টার (IR) থেকে ইন্সট্রাকশন ডিকোড করে। এরপর, এটি প্রয়োজনীয় কন্ট্রোল সিগন্যাল তৈরি করে যা রেজিস্টারসমূহ, ALU এবং সিস্টেম বাসের কার্যক্রম নিয়ন্ত্রণ করে, যার মাধ্যমে ইন্সট্রাকশন সাইকেল সমন্বিত হয়।

সহজ ভাষায় ব্যাখ্যা: উপরের ছবিতে সিপিইউর মেইন অংশগুলো (কন্ট্রোল ইউনিট, ALU, রেজিস্টার) দেখানো হয়েছে। কন্ট্রোল ইউনিট হলো মেইন কন্ট্রোলার। সে নির্দেশ (IR থেকে) পড়ে, বুঝে, তারপর ALU কে বলে হিসাব করতে, রেজিস্টারকে বলে ডেটা নিতে বা দিতে, আর বাসকে বলে ডেটা আনা-নেওয়া করতে। সব কাজ সে সিগন্যাল পাঠিয়ে কন্ট্রোল করে।

একদম সহজ ব্যাখ্যা: ট্র্যাফিক পুলিশ (কন্ট্রোল ইউনিট) যেমন সিগন্যাল দিয়ে গাড়ি (ডেটা), রাস্তা (বাস), আর অন্যান্য পুলিশকে (ALU, রেজিস্টার) কন্ট্রোল করে পুরো ট্র্যাফিক সিস্টেম চালায়।

২। চার বিটের একটি জেনারেল পারপাস রেজিস্টার অঙ্কন করে দেখাও।

পরীক্ষায় লেখার জন্য: একটি ৪-বিটের জেনারেল পারপাস রেজিস্টার (GPR) সাধারণত চারটি ফ্লিপ-ফ্লপ ব্যবহার করে তৈরি করা হয়। এর একটি কমন ক্লক ইনপুট এবং একটি লোড/এনাবল কন্ট্রোল সিগন্যাল থাকে। লোড সিগন্যাল সক্রিয় হলে ক্লক পালসের সাথে সাথে ৪-বিট ইনপুট ডেটা রেজিস্টারে লোড হয়।

টেক্সট-ভিত্তিক ডায়াগ্রাম:


      Data In (D3 D2 D1 D0) ---+----> [+---+---+---+---+] (4 x D Flip-Flops) --+---> Data Out (Q3 Q2 Q1 Q0)
                              |      [|FF3|FF2|FF1|FF0|]                      |
      Load/Enable ------------+-----> [-------C L K-------] <------------------+---- Clock (CLK)

সহজ ভাষায় ব্যাখ্যা: ৪-বিটের একটা রেজিস্টার মানে হলো এটা ৪টা ০ বা ১ একসাথে মনে রাখতে পারে। এটা বানাতে ৪টা ফ্লিপ-ফ্লপ লাগে। একটা 'লোড' সিগন্যাল দিলে আর ক্লক পালস এলে বাইরের ৪টা বিট ভেতরে ঢুকে যায় আর আউটপুটে দেখা যায়।

একদম সহজ ব্যাখ্যা: মনে করো ৪টা লাইট সুইচ আছে যা অন বা অফ (১ বা ০) মনে রাখতে পারে। এটাই ৪-বিটের রেজিস্টার। তুমি একসাথে ৪টা সুইচের অবস্থা সেট করতে পারো।

৩। GPR Based machine-এর Block diagram অঙ্কন করে বিভিন্ন অংশ চিহ্নিত কর।

পরীক্ষায় লেখার জন্য: একটি জেনারেল রেজিস্টার (GPR) ভিত্তিক মেশিনের সরলীকৃত ব্লক ডায়াগ্রাম:


           +---------------------------+
           |     কন্ট্রোল ইউনিট (CU)    |---------+-----> কন্ট্রোল সিগন্যাল
           +-----------+---------------+         |
                       | ডিকোড (IR)             |
                       V                       |
           +-----------+---------------+         |
           | ইন্সট্রাকশন রেজিস্টার (IR)|         |
           +-----------+---------------+         |
                       ^                         |
                       | ইন্সট্রাকশন             |
           +-----------+---------------+         |
           | প্রোগ্রাম কাউন্টার (PC)   |---------+
           +-----------+---------------+         | Address
                       |                         V
           +-----------V---------------+      +-----+
           | মেমরি অ্যাড্রেস রেজি: (MAR)|----->|     |
           +---------------------------+      |  M  |
                                              |  E  |
           +---------------------------+      |  M  |
           | মেমরি বাফার রেজি: (MBR)  |<----->|  O  |
           +-----------+---------------+      |  R  |
                       ^  | ডেটা              |  Y  |
                       |  V                   |     |
           +-----------+--+------------+      +-----+
           | রেজিস্টার ফাইল (GPRs)    |<-----+------- ডেটা (MBR/ALU)
           | (R0, R1, R2, ...)         |------>------- অপারেন্ড (ALU/MBR)
           +-----------+---------------+
                       ^  |
                       |  V অপারেন্ড/ফলাফল
           +-----------+---------------+
           |       ALU                 |
           +---------------------------+

অংশগুলো: কন্ট্রোল ইউনিট (CU), অ্যারিথমেটিক লজিক ইউনিট (ALU), রেজিস্টার ফাইল (GPRs), প্রোগ্রাম কাউন্টার (PC), ইন্সট্রাকশন রেজিস্টার (IR), মেমরি অ্যাড্রেস রেজিস্টার (MAR), মেমরি বাফার রেজিস্টার (MBR), প্রধান মেমরি (Memory), সিস্টেম বাস।

সহজ ভাষায় ব্যাখ্যা: জেনারেল রেজিস্টার মেশিনের ছবিতে অনেকগুলো জেনারেল পারপাস রেজিস্টার (GPRs) থাকে যা ডেটা বা অ্যাড্রেস রাখতে পারে। ALU এই রেজিস্টারগুলো থেকে ডেটা নিয়ে কাজ করে এবং ফলাফল রেজিস্টারে রাখতে পারে। কন্ট্রোল ইউনিট পুরো প্রক্রিয়াটা নিয়ন্ত্রণ করে।

একদম সহজ ব্যাখ্যা: এটা এমন একটা রান্নাঘর যেখানে একটামাত্র বাটির বদলে অনেকগুলো ছোট ছোট বাটি (GPR) আছে। বাবুর্চি (ALU) যেকোনো বাটি থেকে মশলা বা সবজি নিতে পারে, আবার রান্না করা জিনিস যেকোনো বাটিতে রাখতে পারে।

৪। 4-bit ALU সার্কিট অঙ্কন কর।

পরীক্ষায় লেখার জন্য: একটি ৪-বিট ALU (Arithmetic Logic Unit) এর লজিক সার্কিট টেক্সট-ভিত্তিক ডায়াগ্রামে আঁকা জটিল। তবে এর ব্লক ডায়াগ্রাম নিচে দেওয়া হলো:


      A (4-bit) --+---------------------+---> F (4-bit Result)
                  |     +---------+     |
      B (4-bit) --+---->| 4-bit   |     |
                  |     | Adder/  |     |
      Cin --------+---->| Logic   |-----+---> Flags (C, Z, S, V)
                  |     | Circuit |     |
      Function----->|     +---------+     |
      Select (S)    |                     |
                    +---------------------+ (4-bit ALU)

এটি দুটি ৪-বিট ইনপুট (A, B) ও ফাংশন সিলেক্ট ইনপুট (S) নেয় এবং একটি ৪-বিট ফলাফল (F) ও স্ট্যাটাস ফ্ল্যাগ তৈরি করে। এর অভ্যন্তরে অ্যাডার ও লজিক গেট থাকে।

সহজ ভাষায় ব্যাখ্যা: ৪-বিট ALU আঁকা কঠিন, কিন্তু এটা দুটো ৪-বিটের সংখ্যা (A, B) নেয়। কন্ট্রোল সিগন্যাল (Function Select) ঠিক করে দেয় কী কাজ করতে হবে (যোগ, বিয়োগ, AND, OR ইত্যাদি)। ALU সেই কাজটা করে ৪-বিটের একটা ফলাফল (F) আর কিছু স্ট্যাটাস ফ্ল্যাগ দেয়।

একদম সহজ ব্যাখ্যা: এটা একটা ৪-বিট ক্যালকুলেটর। তুমি দুটো ৪-বিটের সংখ্যা দাও আর বলে দাও কী করতে হবে, এটা সেটা করে ফলাফলটা আর কিছু স্ট্যাটাস (যেমন: হাতে আছে কিনা) তোমাকে বলে দেয়।

৫। স্ট্রেইটলাইন সিকুয়েন্সিং বলতে কী বুঝ?

পরীক্ষায় লেখার জন্য: স্ট্রেইটলাইন সিকুয়েন্সিং (Straight-line Sequencing) হলো প্রোগ্রাম এক্সিকিউশনের সবচেয়ে সরল পদ্ধতি যেখানে সিপিইউ মেমরিতে সংরক্ষিত ইন্সট্রাকশনগুলোকে তাদের অবস্থানের ক্রম অনুযায়ী (consecutive order) একটির পর একটি ফেচ এবং এক্সিকিউট করে। প্রোগ্রাম কাউন্টার (PC) প্রতিটি ইন্সট্রাকশন ফেচের পর স্বাভাবিকভাবে পরবর্তী ইন্সট্রাকশনের ঠিকানা নির্দেশ করার জন্য ইনক্রিমেন্ট হয়। এই পদ্ধতিতে কোনো ব্রাঞ্চ বা জাম্প ইন্সট্রাকশন থাকে না।

সহজ ভাষায় ব্যাখ্যা: স্ট্রেইটলাইন সিকুয়েন্সিং মানে হলো প্রোগ্রামটা একদম সোজা লাইনে একটার পর একটা নির্দেশ পালন করে যাওয়া। কোনো লাফঝাঁপ বা শর্ত চেক করে অন্য জায়গায় চলে যাওয়া – এসব থাকে না।

একদম সহজ ব্যাখ্যা: রান্নার রেসিপির নির্দেশগুলো একটার পর একটা வரிசையாக ফলো করে যাওয়া, কোনো লাইন বাদ না দিয়ে।

৬। Intelligent monitor interface-এর ব্লকচিত্র অঙ্কন করে সংক্ষেপে লেখ।

পরীক্ষায় লেখার জন্য: ইন্টেলিজেন্ট মনিটর ইন্টারফেস বলতে সাধারণত আধুনিক গ্রাফিক্স অ্যাডাপ্টার বা ভিডিও কার্ডকে বোঝানো হয়, যার নিজস্ব প্রসেসিং ইউনিট (GPU), মেমরি (VRAM) এবং কন্ট্রোল লজিক থাকে। এটি সিপিইউর উপর চাপ কমিয়ে ডিসপ্লে সম্পর্কিত কাজগুলো নিজেই সম্পাদন করে।

ব্লক ডায়াগ্রাম (ধারণা):


      +-----+      +--------------+      +-----------------+      +---------+
      | CPU |<---->| সিস্টেম বাস   |<---->| গ্রাফিক্স কার্ড   |<---->| মনিটর  |
      +-----+      +--------------+      | (ইন্টারফেস)     |      +---------+
                                         | +-------+-------+ |
                                         | |  GPU  | VRAM  | |
                                         | +-------+-------+ |
                                         | | ডিসপ্লে কন্ট্রোল | |
                                         | +---------------+ |
                                         +-----------------+

এখানে GPU গ্রাফিক্স প্রসেস করে, VRAM ফ্রেম বাফার ও টেক্সচার রাখে, এবং ডিসপ্লে কন্ট্রোলার মনিটরে সিগন্যাল পাঠায়।

সহজ ভাষায় ব্যাখ্যা: ইন্টেলিজেন্ট মনিটর ইন্টারফেস হলো তোমার কম্পিউটারের গ্রাফিক্স কার্ড। এটার নিজের ব্রেইন (GPU) আর মেমরি (VRAM) আছে। মনিটরে ছবি দেখানোর কাজগুলো সে নিজেই করে ফেলে, মেইন সিপিইউকে বেশি চাপ দেয় না।

একদম সহজ ব্যাখ্যা: সিনেমা হলের প্রজেক্টর মেশিনটা নিজেই ছবি প্রসেস করতে পারে। গ্রাফিক্স কার্ডও এরকম একটা 'বুদ্ধিমান' ইন্টারফেস যা ডিসপ্লের কাজ নিজেই সামলায়।

রচনামূলক প্রশ্ন:

১। একটি সাধারণ CPU মডেলের বর্ণনা দাও।

পরীক্ষায় লেখার জন্য:

একটি সাধারণ সিপিইউ (সেন্ট্রাল প্রসেসিং ইউনিট) মডেল নিম্নলিখিত প্রধান অংশগুলো নিয়ে গঠিত:

  1. কন্ট্রোল ইউনিট (CU): সিস্টেমের কার্যক্রম নিয়ন্ত্রণ ও সমন্বয় করে, ইন্সট্রাকশন ফেচ, ডিকোড ও এক্সিকিউট করার জন্য সিগন্যাল পাঠায়।
  2. অ্যারিথমেটিক লজিক ইউনিট (ALU):** সকল গাণিতিক ও যৌক্তিক অপারেশন সম্পাদন করে।
  3. রেজিস্টারসমূহ (Registers):** সিপিইউর ভেতরের দ্রুতগতির অস্থায়ী মেমরি। এর মধ্যে আছে:
    • জেনারেল পারপাস রেজিস্টার (GPRs)
    • প্রোগ্রাম কাউন্টার (PC)
    • ইন্সট্রাকশন রেজিস্টার (IR)
    • মেমরি অ্যাড্রেস রেজিস্টার (MAR)
    • মেমরি বাফার রেজিস্টার (MBR/MDR)
    • ফ্ল্যাগ রেজিস্টার (Status Register)
  4. সিপিইউ ইন্টারনাল বাস (CPU Internal Bus):** ভেতরের অংশগুলোর মধ্যে ডেটা ও সিগন্যাল আদান-প্রদান করে।

সিপিইউ মূলত ফেচ-ডিকোড-এক্সিকিউট চক্র অনুসরণ করে কাজ করে।

সহজ ভাষায় ব্যাখ্যা: একটা সাধারণ সিপিইউর মধ্যে মূলত তিনটা জিনিস থাকে:

  1. কন্ট্রোল ইউনিট (CU): ম্যানেজার।
  2. ALU: ক্যালকুলেটর।
  3. রেজিস্টার: কাজের জন্য দরকারি ছোট ছোট অনেকগুলো ফাস্ট মেমরি বা খাতা।

এরা সবাই ভেতরের রাস্তা (Internal Bus) দিয়ে যোগাযোগ করে আর ফেচ-ডিকোড-এক্সিকিউট চক্র মেনে কাজ করে।

একদম সহজ ব্যাখ্যা: তোমার ব্রেইনের মতো। একটা অংশ কন্ট্রোল করে (CU), একটা অংশ চিন্তা বা হিসাব করে (ALU), আর অনেকগুলো জায়গা আছে যেখানে তুমি তাৎক্ষণিক তথ্য মনে রাখো (রেজিস্টার)।

২। ৪-বিট জেনারেল রেজিস্টার-এর ব্লক ডায়াগ্রাম অঙ্কন করে বর্ণনা দাও।

পরীক্ষায় লেখার জন্য:

৪-বিট জেনারেল পারপাস রেজিস্টার: এটি ৪টি বিট ডেটা অস্থায়ীভাবে সংরক্ষণ করতে পারে এবং সাধারণত ৪টি প্যারালাল ডি ফ্লিপ-ফ্লপ দিয়ে তৈরি।

ব্লক ডায়াগ্রাম:


         Data Inputs          +-----+-----+-----+-----+
             D3 ------------->| D   | D   | D   | D   |
             D2 ------------->|  Q3 |  Q2 |  Q1 |  Q0 |<--- Data Outputs
             D1 ------------->| FF3 | FF2 | FF1 | FF0 |
             D0 ------------->|     |     |     |     |
                              +-----+-----+-----+-----+
                                  ^     ^     ^     ^
                                  |     |     |     |
      Load/Enable Signal ---------+-----+-----+-----+------> (To all FF Enable/Load)
      Clock (CLK) --------------+-----+-----+-----+------> (To all FF Clock)

বর্ণনা: ৪টি ফ্লিপ-ফ্লপ (FF0-FF3) প্রতি ক্লক সাইকেলে লোড/এনাবল সিগন্যাল সক্রিয় থাকলে ৪-বিট ইনপুট ডেটা (D0-D3) গ্রহণ করে এবং আউটপুটে (Q0-Q3) ধারণ করে রাখে।

সহজ ভাষায় ব্যাখ্যা: ৪-বিট রেজিস্টার হলো ৪টা বিট মনে রাখার বাক্স। এটা বানাতে ৪টা ফ্লিপ-ফ্লপ লাগে। যখন তুমি 'লোড' বাটনে চাপ দাও আর ঘড়ির টিক বাজে, তখন ইনপুটে থাকা ৪টা বিট বাক্সের ভেতর ঢুকে যায় আর আউটপুটে দেখা যায়।

একদম সহজ ব্যাখ্যা: ৪টা লাইট সুইচের প্যানেল। একটা মাস্টার 'লোড' সুইচ আছে। এই মাস্টার সুইচ অন করে তুমি যদি ৪টা লাইটের সুইচ অন/অফ করো, তাহলে লাইটগুলো সেই অবস্থায় সেট হয়ে যাবে।

৩। ৪-বিট সমান্তরাল অ্যাডার-এর ব্লক ডায়াগ্রাম অঙ্কন করে বর্ণনা দাও।

পরীক্ষায় লেখার জন্য:

৪-বিট সমান্তরাল অ্যাডার (4-bit Parallel Adder): এটি একটি ডিজিটাল সার্কিট যা দুটি ৪-বিট বাইনারি সংখ্যাকে যোগ করে একটি ৪-বিট যোগফল (Sum) এবং একটি ক্যারি-আউট (Cout) তৈরি করে। এটি চারটি ফুল অ্যাডার (FA) সার্কিটকে ক্যাসকেড সংযোগে ব্যবহার করে তৈরি হয়।

ব্লক ডায়াগ্রাম:


         A3 A2 A1 A0     B3 B2 B1 B0  (Inputs)
         |  |  |  |        |  |  |  |
         V  V  V  V        V  V  V  V
      +----+    +----+    +----+    +----+
 Cin--->| FA |---->| FA |---->| FA |---->| FA |---> Cout
      | (0)| C1 | (1)| C2 | (2)| C3 | (3)|
      +--+-+    +--+-+    +--+-+    +--+-+
         |        |        |        |
         V        V        V        V
        S0       S1       S2       S3     (Sum Output)

বর্ণনা: প্রতিটি ফুল অ্যাডার দুটি ইনপুট বিট এবং আগের স্টেজ থেকে আসা ক্যারি-ইন যোগ করে একটি সাম বিট ও একটি ক্যারি-আউট তৈরি করে। ক্যারি-আউটটি পরবর্তী স্টেজে যায়।

সহজ ভাষায় ব্যাখ্যা: ৪-বিট প্যারালাল অ্যাডার হলো এমন একটা সার্কিট যা দুটো ৪-বিটের বাইনারি সংখ্যা যোগ করতে পারে। এটা বানাতে ৪টা ফুল অ্যাডার লাগে। প্রথম ফুল অ্যাডার প্রথম বিট দুটো যোগ করে, তার হাতে থাকাটা দ্বিতীয় ফুল অ্যাডারকে দেয়, وهكذا চলতে থাকে।

একদম সহজ ব্যাখ্যা: তুমি যখন দুটো ৪ অংকের সংখ্যা নিচে নিচে রেখে যোগ করো, তখন ডানদিক থেকে যোগ করে হাতে থাকা সংখ্যাটা বামের অংকের সাথে যোগ করো। ৪-বিট প্যারালাল অ্যাডারও অনেকটা এভাবেই কাজ করে।

৪। 4-bit ALU ব্লক ডায়াগ্রাম অঙ্কন করে বর্ণনা দাও।

পরীক্ষায় লেখার জন্য:

৪-বিট অ্যারিথমেটিক লজিক ইউনিট (4-bit ALU): এটি একটি ডিজিটাল সার্কিট যা দুটি ৪-বিট অপারেন্ডের উপর বিভিন্ন গাণিতিক ও যৌক্তিক অপারেশন সম্পাদন করতে পারে, যা ফাংশন সিলেক্ট লাইন দ্বারা নির্ধারিত হয়।

ব্লক ডায়াগ্রাম (ধারণা):


             A [4]       B [4]   Cin
              |           |       |
              V           V       V
      +-------+-----------+-------+
      |       |           |       |
      | +--- Arith Circuit ----+ | -----> Arithmetic Result
      | |                       | |
      | +-----------------------+ |
      |       |           |       |
      | +---- Logic Circuit ----+ | -----> Logic Result
      | |                       | |
      | +-----------------------+ |
      |       |           |       |
      |       V           V       V
      | +-----------------------+ |
      | |      Multiplexer      | | --> F [4] (Final Result)
      | +-----------------------+ |
      |            ^              | -----> Flags (Cout, Z, S, V)
      +------------+--------------+
                   |
          Function Select [k] (Control)

বর্ণনা: ALU দুটি ৪-বিট ইনপুট (A, B) ও কন্ট্রোল সিগন্যাল (Function Select) নেয়। এর ভেতরে অ্যারিথমেটিক সার্কিট ও লজিক সার্কিট থাকে। কন্ট্রোল সিগন্যাল অনুযায়ী মাল্টিপ্লেক্সার সঠিক অপারেশনের ফলাফল (F) আউটপুটে পাঠায় এবং স্ট্যাটাস ফ্ল্যাগ তৈরি করে।

সহজ ভাষায় ব্যাখ্যা: ৪-বিট ALU হলো একটা সার্কিট যা দুটো ৪-বিটের সংখ্যা নিয়ে যোগ, বিয়োগ, AND, OR ইত্যাদি অনেক রকম কাজ করতে পারে। বাইরে থেকে সিগন্যাল দিয়ে বলে দিতে হয় কোন কাজটা করতে হবে। এটা কাজের পর ফলাফল আর কিছু স্ট্যাটাস ফ্ল্যাগ দেয়।

একদম সহজ ব্যাখ্যা: এটা একটা মাল্টি-ফাংশনাল ক্যালকুলেটর। তুমি দুটো ৪-বিটের সংখ্যা দাও আর বলে দাও কী করতে হবে (যোগ/বিয়োগ/AND/OR)। এটা সেই কাজটা করে ফলাফল আর কিছু স্ট্যাটাস তোমাকে দেয়।
